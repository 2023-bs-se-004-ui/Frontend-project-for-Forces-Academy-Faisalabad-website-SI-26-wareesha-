# Forces Academy Faisalabad Website

A responsive educational website developed using HTML, CSS, Bootstrap, and JavaScript.

Forces Academy Faisalabad's official website showcases the academy's programs, admissions process, results, campus gallery, and contact information — built with a clean navy-and-gold theme, smooth animations, and a fully responsive layout for desktop, tablet, and mobile.

---

##  Features

- Fully responsive design (mobile, tablet, desktop)
- Sticky navigation bar with active-page highlighting
- Animated hero section with entrance transitions
- Animated statistics counter (students, years, courses, success rate)
- Courses page with detailed program cards
- Admissions, Results, Gallery, and Contact pages
- Testimonials slider (Swiper.js)
- Scholarship / demo class / urgent admission alert banners
- Highlighted **Student Portal** button for quick access
- Smooth scroll navigation
- Back-to-top button
- Consistent navy blue, gold, and white theme across all pages

##  Getting Started

   ```bash

   ```
2. Open `index.html` in your browser, or serve the folder with any static server.
3. To deploy, enable **GitHub Pages** in the repository settings (branch: `main`, folder: `/root`).
